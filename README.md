# 🧮 Simple Math CLI

![Screenshot 2025-04-25 074407](https://github.com/user-attachments/assets/db80b8c9-cec6-490e-9c09-d3156918a2fe)


A fun and simple command-line math quiz built with Node.js. Test your basic math skills right from your terminal!

---

## 🚀 Features

- ➕ Addition  
- ➖ Subtraction  
- ✖️ Multiplication  
- ➗ Division  
- 🎯 Random math questions  
- ✅ Instant answer validation  

---

## 🛠 Prerequisites

- Node.js installed on your system (Download from [nodejs.org](https://nodejs.org))

---

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/chandisarandeni/simple-math.git

# Navigate into the project directory
cd simple-math

# Install dependencies
npm install
```

---

## ▶️ Running the App

```bash
npm start
```

**💡 Tip:**  
If the terminal behaves oddly:  
- Press `CTRL + C` to stop  
- Type `cls` to clear the screen (on Windows)  
- Run `npm start` again

---

## 🧑‍💻 How It Works

1. A random math question appears in the terminal  
2. You type your answer and hit Enter  
3. The program checks and tells you if it’s correct  

---

## ✨ Example

```
What is 7 * 6?
Your answer: 42

✅ Correct!
```

```
What is 10 / 2?
Your answer: 6

❌ Wrong. The correct answer is 5
```
